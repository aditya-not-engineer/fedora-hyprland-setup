# Hyprland Keybindings

These are the main keyboard shortcuts currently used in my Fedora + Hyprland setup.

The main modifier is:

**SUPER = Windows key**

---

## Applications

| Shortcut | Action |
|---|---|
| `SUPER + Enter` | Open terminal |
| `SUPER + B` | Open browser |
| `SUPER + E` | Open file manager |
| `SUPER + Ctrl + E` | Open emoji picker |
| `SUPER + C` | Open calculator |
| `SUPER + Ctrl + Enter` | Open application launcher |

---

## Window Management

| Shortcut | Action |
|---|---|
| `SUPER + Q` | Close active window |
| `SUPER + Shift + Q` | Quit active window and its open instances |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + M` | Toggle maximize |
| `SUPER + T` | Toggle floating |
| `SUPER + Shift + T` | Toggle floating for all windows in workspace |
| `SUPER + Alt + T` | Toggle floating and pinned |
| `SUPER + J` | Toggle split |
| `SUPER + K` | Swap split |

### Move Focus

| Shortcut | Action |
|---|---|
| `SUPER + Left` | Focus window on the left |
| `SUPER + Right` | Focus window on the right |
| `SUPER + Up` | Focus window above |
| `SUPER + Down` | Focus window below |

### Move / Resize Windows

| Shortcut | Action |
|---|---|
| `SUPER + Alt + Left` | Swap window left |
| `SUPER + Alt + Right` | Swap window right |
| `SUPER + Alt + Up` | Swap window up |
| `SUPER + Alt + Down` | Swap window down |
| `SUPER + Shift + Left` | Reduce window width |
| `SUPER + Shift + Right` | Increase window width |
| `SUPER + Shift + Up` | Reduce window height |
| `SUPER + Shift + Down` | Increase window height |

---

## Workspaces

| Shortcut | Action |
|---|---|
| `SUPER + 1-9` | Switch to workspace |
| `SUPER + 0` | Switch to workspace 10 |
| `SUPER + Shift + 1-9` | Move window to workspace |
| `SUPER + Shift + 0` | Move window to workspace 10 |
| `SUPER + S` | Toggle scratchpad |
| `SUPER + Shift + S` | Move active window to scratchpad |
