# Quick Dictionary

## Linux

Linux is the kernel at the core of many operating systems.

Think of the kernel as the layer that allows software to communicate
with the computer's hardware.

Linux itself is not the same thing as Fedora.

---

## Distribution (Distro)

A Linux distribution packages the Linux kernel together with software,
libraries, package management, installers, and other components needed
to create a usable operating system.

Examples include:

- Fedora
- Ubuntu
- Debian
- Arch Linux
- openSUSE

---

## Fedora

Fedora is the Linux distribution used by this workstation.

It provides the operating-system foundation on top of which the rest of
this setup is built.
